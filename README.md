# PokéMMO Raids Guide 🚀

Guía interactiva optimizada para incursiones (raids) de PokéMMO basada en las recomendaciones de **MigueCabeza**.

## 🛠️ Tecnologías utilizadas
- **Vite.js** (Empaquetador ultrarrápido)
- **Vanilla JS (ES Modules)** (Código limpio, ligero y modular)
- **Tailwind CSS** (Estilos modernos con modo oscuro nativo)

## 💻 Desarrollo Local
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```

## 🚀 Despliegue en GitHub Pages
El proyecto incluye un flujo de trabajo automático de GitHub Actions en `.github/workflows/deploy.yml`.

1. Sube este proyecto a tu repositorio de GitHub (rama `main`).
2. Ve a los **Settings** de tu repositorio -> **Pages**.
3. En **Source**, selecciona **GitHub Actions**.
4. ¡Listo! Tu web se compilará y desplegará automáticamente cada vez que hagas `git push`.
